# Gym App - Front end

The **Gym App** is a mobile application designed to enhance your fitness journey. Built with **React Native**, it provides users with a seamless experience to track workouts, manage profiles, and stay consistent with their fitness goals.

## Features

- **User Registration**: Sign up and manage your account with ease.  
- **Workout History**: Keep track of your completed workouts and monitor your progress.  
- **Profile Configuration**: Customize your profile with personal details and preferences.  
- **Exercise List**: Browse a variety of exercises, mark them as completed, and maintain consistency in your routine.  

## Technologies Used

- **Frontend**: [React Native](https://reactnative.dev/) for cross-platform mobile app development.  
- **Backend**: [Node.js](https://nodejs.org/) with [Fastify](https://www.fastify.io/) for a fast and lightweight API.  
- **Database**: [MongoDB](https://www.mongodb.com/) for storing user and workout data.

## Getting Started

Follow these steps to set up and run the project locally:

### Prerequisites

- Node.js and npm installed.  
- A MongoDB instance or access to MongoDB Atlas.  
- Android Studio or Xcode for mobile emulation (optional).
